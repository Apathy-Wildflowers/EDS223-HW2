# EDS223-HW2

This repository uses tmap and ggplot to create maps and visualizations of redlined areas in Los Angeles and their relation to percentage low income,
exposure to particulate matter 2.5, and bike and pedestrian crashes.

"HW2.qmd" has all the code chunks to create said maps and exploratory pdf.

# Data

Data comes from https://pedp-ejscreen.azurewebsites.net/, an unofficial copy of EJScreen, which is a 
tool created by the United States Environmental Protection Agency to map out Environmental Injustices across the United States. 

HOLC Redlining data comes from the mapping inequality project (https://dsl.richmond.edu/panorama/redlining/#loc=5/39.1/-94.58) by
the University of Richmond.

Crash data comes from the Transformation Information Mapping System (https://tims.berkeley.edu/) by the UC Berkeley.
Authors: Liam Sarmiento
